# Conditional lead-optimization decision pilot

Task transition: after the live model-free request failed and the user clarified
that optimization requires property-model selection, admission now requires at
least one explicit model. The user chose to switch to a supported platform
property objective. The DRD2 rules in this document describe the earlier reference
task; they cannot evaluate the new objective. A new baseline, model/units,
objective rules and evaluation contract must be qualified before its campaign.

This fresh development experiment asks whether a supplied algorithm and then a
specialist help choose **one follow-up after common initial observations**. It
compares task-guided main policies with delegation. It does not test unrestricted
Agent Scientist discovery, reproduce the paper's generator training,
or resume/rewrite an existing campaign. Optimization is the first workflow;
de novo design needs a separate task policy and evaluator later.

## Freeze before observations

The run owner saves `build_protocol(...)` JSON and its digest before importing
generated outcomes or asking for model decisions. It binds the public lead/form,
unrounded baseline, scorer/model/runtime, source CSVs, normalized identities,
structural material and lookup index. Original unspecified stereo is retained.
Input drift requires a fresh run/protocol, not a silent repair of frozen inputs.

Freeze the exact local `smallmol-investigation` definition before outcomes:
its file hash, name, purpose, instructions, expected output and explicit empty
tool/skill/module/child/source grants, plus its positive integer `max_iterations`
and `timeout_seconds` limits. Enabled state and revision are lifecycle
metadata, excluded from semantic matching; the full source file hash is retained.
The same frozen purpose, instructions and output guidance are included in every
arm's scientific context, so the baseline is a task-guided main policy. Native
launch must compare the current saved child's semantic content with this frozen
definition and reject changes. The assessment adapter and intake-audit source
files are also hash-bound; the run owner records remaining implementation hashes.

Reviews are our **internal computational development checks**. No external SME
gate is required. Unknown isolated edits, sites, causal effects and library
behavior remain unknown; existing review/approval flags are not rewritten.
Database membership and source checks are not expert chemical endorsement.

Generation uses the existing NodeAPI connector for `Fragment_Based_Optimization`.
Reference and uploaded-library identity are fixed. Model-selection fields
must explicitly select at least one property model; missing or empty selections
are rejected before upload. The existing connector owns current schema, file and
authorization checks. No custom model IDs are invented. No alternative HTTP
client or local scientific fallback is introduced.

## Initial observations and stopping

Collect one mixed-reference batch. Bind it to the request, source/upload identity,
job ID, terminal receipt, downloaded-artifact hash and complete-output declaration.
Retain every raw row, invalid result, duplicate and cross-batch provenance. Assess
each distinct valid exact canonical form once per arm using the pinned scorer.
Baseline assessment overhead is separate from candidate evaluations.

For reasoning, factor repeated assay metadata and molecular forms out of the
per-row records. Retain every candidate summary, structure, raw score, invalid,
unresolved and duplicate row, including extra source columns. A versioned context
projection declares redundant transport fields omitted from the prompt and binds
the full private batch by hash. It performs no candidate selection or truncation.
The native driver supplies the frozen role once, outside assignment data. If
assignment data still exceed its 24,000-character technical allowance, block the
decision explicitly; this limit is not a token budget or a scientific stop rule.

Success requires the **same valid, distinct, nonbaseline candidate** to have
DRD2 P(active) strictly above `0.7190727026540751`, QED strictly above
`0.800452829768805`, and original-lead Morgan count-radius-2 similarity strictly
above `0.7`. Compare unrounded values. Do not substitute hosted predictions,
weighted rewards or inclusive thresholds. These are computational predictions
and descriptors, not receptor pharmacology or measured potency.

If the common batch succeeds, record `no_remaining_decision` and stop. Do not
manufacture a specialist opportunity or label unrun arms completed comparisons.
Otherwise each arm may choose at most one follow-up library or abstain. This
one-step horizon defines the pilot question, not a general tool budget.

## Matched arms and routing

| Arm | Provided treatment |
| --- | --- |
| `base` | Main-agent decision from the common admissible evidence |
| `base_algorithm` | Same main decision plus reusable coverage calculations |
| `base_algorithm_specialist` | Same helper/evidence/guidance plus named specialist |

Base versus helper tests providing the algorithm. Helper versus specialist tests
delegation only if scientific guidance, admissible information, tools, safeguards,
model settings and allowances match. Register those runtime settings before actual
decisions. Record every parent/child call, failed attempt, token count, time and
known or unknown charge. Extra reasoning is not free.

The native driver verifies the configured model/provider identity and rejects
separate delegation inference overrides it recognizes. Complete sampling-setting
equivalence and fresh-session equivalence remain caller assumptions, not fully
verified guarantees. The role limits are frozen, but that alone does not establish
equal actual reasoning consumption. This is a bounded, task-guided decision
comparison; a difference in outcomes does not establish a causal specialist gain.

For an unfinished common task with a meaningful remaining choice, the specialist
arm **requires an actual native named-child invocation** of
`smallmol-investigation`. A missing invocation is `routing_failure` or
`not_exercised`; main-only fallback must not be counted as specialist execution.
Imported advice JSON alone is not invocation evidence. This pilot enforces the
eligible route so scientific decision quality can be studied. Natural-language
routing recall is a separate later study; general routing is not installed or
certified by this protocol. Common first success stops before routing any arm.

## Accounting, recovery and evidence

Shared initialization is physically executed once. Report that actual work
separately, and attribute identical initial evidence/effort to every arm when
comparing arm totals. Do not report shared precomputation as free agent work or
multiply it into the physical once-only total. Equal source/library/job counts
are not equal internal generation, compute or credits. No numerical candidate,
credit or reasoning caps are invented; unknowns remain explicit. Agree and version
any later limits before using them.

Persist intent before dispatch. A timeout or ambiguous submit outcome remains
`unknown`, even without a returned job ID. Do not replace or repeat it before
reconciling the original attempt. Polling transport errors are not scientific
job failure. Local import/assessment recovery reuses receipts, not new science.

Keep scientific-attempt and assessment ledgers separate. Retain requested,
observed, estimated and unknown consumption. Import explicit data artifacts;
do not execute archives or arbitrary serialized objects. Associate molecular
identities by checked structures/forms, never CSV row order.

Fixture outputs, imported NodeAPI artifacts, actual connector runs, imported policy
decisions and native agent executions are different evidence kinds. Imported JSON
does not prove an agent ran. A three-arm agent comparison requires actual runtime
evidence; otherwise report exactly which engineering/import steps were exercised.

## Evaluation and interpretation

Report joint task success, raw score differences, constraint satisfaction, unique
candidate evaluations, invalids/duplicates, execution failures, unresolved attempts,
abstention and all reasoning/compute costs. Lookup coverage is a supporting metric.
This single public lead and known source cohort provide descriptive development
findings, not protected-holdout performance, classifier-training independence or
general specialist superiority. Report comparisons descriptively, with sampling,
session-freshness and resource-accounting limitations; do not claim causal gains.
Keep private receipts, job artifacts, credentials
and model traces outside a source release. No Git publication is authorized.
