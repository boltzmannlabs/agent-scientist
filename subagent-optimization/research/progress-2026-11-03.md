## What we built

- A runnable conditional pilot for one concrete scientific decision: choose a
  follow-up fragment library when the initial optimization has not met the objective.
- Persistent run state with frozen inputs, request/library identities, original
  submission receipts, independent comparison-arm state and local result recovery.
  An uncertain submission blocks automatic repetition.
- A thin adapter to Agent Scientist's existing Boltzmann upload, submit, status
  and download tools. Scientific generation remains in the existing platform tools.
- A mandatory property-model check before new optimization uploads/submissions.
  Missing objectives fail locally; historical jobs remain available for monitoring.
- Complete CSV intake with strict molecular identities, duplicate/conflict handling,
  retained raw rows, property evidence and local QED/fingerprint calculations.
- Reusable assessment caches and compact decision context. Repeated metadata is
  factored out while candidate rows remain available; oversized assignments fail
  explicitly rather than silently dropping evidence.
- A native named-specialist decision path. Imported advice cannot establish that
  the specialist actually ran. Canned SDK checks cover real main/child routing,
  role consistency and advisory-only tool permissions.
