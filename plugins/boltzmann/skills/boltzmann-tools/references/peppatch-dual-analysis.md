# PepPatch preparation and dual-analysis results

This guide has been superseded by [PepPatch input preparation and output
interpretation](peppatch-complex-inputs.md).

Use that guide for protein PDBs, sole-PDB protein ZIPs and protein–ligand ZIPs
with explicit reference chemistry and atom mappings. The previous restriction
to protein-only raw PDB inputs no longer applies. Both result CSVs remain in
the existing primary output ZIP. No new scientific request fields or local
chemistry installation are required. Existing authorization and partial-validation
approval rules remain in force.
