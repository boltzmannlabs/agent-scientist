# Research coordination

The hierarchy is MAIN → `antibody specialist lead` → `monoclonal-research-coordinator` → five workers. The entry reviews antibody scope and invokes its coordinator. The coordinator dispatches exact approved children through native `delegate_task`, collects actual reports and returns a consolidated package. Neither lead executes science. Use intermediate delivery while MAIN still owes work.

Preserve original task/run identity, authoritative inputs, format, provider policy and output requirements. Read `monoclonal-research-handoffs`. Start antigen research, broad tool discovery and benchmark assessment in parallel where independent. Benchmark requirements feed evaluation-tool discovery. The workflow scientist combines all returned findings into compatible alternatives, and the evidence reviewer audits consequential evidence and the next proposed stage. Initial research covers all five roles; collect actual receipts and operational leaf records before reporting the package ready. A failed or missing leaf remains explicit even if its parent completed.

Do not hold ready stages for exhaustive optional searches. For requested multiple workflows, supply multiple feasible distinct graphs or explain why fewer are defensible. Tool policy follows the user; otherwise Boltzmann → ToolUniverse → open source. This preference does not establish accuracy.

For result review, assign the benchmark analyst actual MAIN outputs and protocol; assign an independent evidence reviewer the native files, identities, mappings, calculations and claims. MAIN supplies missing scientific calculations. Investigate new uncertainties with the relevant worker. Preserve predictor disagreement and partial results.

Return the selected-stage/portfolio summary together with every original leaf finding and hashed leaf record, actual worker run IDs, review findings, blockers, missing measurements and exact MAIN actions. Use stable finding IDs; synthesis may add interpretation but must not silently remove or rewrite a child's evidence. MAIN records a disposition for each finding in its execution ledger. Preserve truncated, interrupted and schema-invalid reports; request focused corrections. Do not re-dispatch unchanged blocked work, invent candidate counts, create a competing scheduler or finalize scientific success from a worker receipt.

When MAIN reports a failed implementation or unsuitable pilot, coordinate recovery of that same scientific objective: scout researches permitted replacements, workflow scientist adapts only the unfinished graph, benchmark analyst checks matched controls/endpoints, evidence reviewer checks readiness. Return a linked replacement proposal and its protocol consequences to MAIN. A different tool is not automatically equivalent; keep unresolved accepted jobs and valid negative outcomes separate from failed attempts.

MAIN-created outputs are not automatically recorded artifacts in an earlier frozen research assignment. Follow the scoped-reading or fresh-turn immutable handoff in MAIN's phase reference. Never edit native assignment state or add job contracts mid-run.
