# Applications and honest readiness

The specialist routes thirteen CRISPR application classes but does not implement thirteen complete design pipelines. Its directly packaged executables perform metadata policy, dependency planning and evidence QA; real scientific stages use separately supplied native backends. Historical model execution is not proof of this revision's live-agent adherence or recipient readiness.

## Remaining routes and boundaries

001: intake/router only, not activity accuracy.
003: therapeutic research review; no delivery, clinical efficacy or safety certification.
004: variant-correction routing to a verified BE/PE endpoint; no separate complete application benchmark.
007: CRISPRi/a needs original chromatin/genome features; source import is not an efficacy benchmark.
008: epigenome requires measured functional silencing/methylation; no CpG-density substitute.
010: only approved non-pathogen/contrived assay analysis; pathogen-associated operational design/optimization is review-only.
011: pooled-library planning needs library-level outcomes/controls; guide correlation does not validate screen power.
012: plant design remains inactive without a verified species adapter; publication existence does not activate it.
013: only confirmed non-pathogenic microbial context with native bacterial evidence; mammalian scores cannot substitute.

## Modes

AUDIT: input contracts, provenance, source exposure, stage honesty, artifact integrity and endpoint compatibility.
BENCHMARK: approved measured-label/native-inference evaluation, validation-only configuration selection and completed-only publication.
EVALUATE: evaluate supplied existing candidates only with a verified matching native endpoint.
DESIGN: conditional parent-approved design with real reference/native enumeration/scoring/specificity; package tests do not demonstrate it.
EXPLORATORY: hypothesis generation and feasibility review, explicitly separated from validated performance.

See references/modality-map.md for detailed task boundaries. Keep RNAi/siRNA out of scope. No best biological design or experimental validation is supplied by this package.
