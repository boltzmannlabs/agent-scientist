# Evidence and publication rules

Never add heuristic substitute scores to complete a scientific pipeline. A completed model/endpoint benchmark need not validate the full application. Installation, import, metadata checks and mock fixtures are not native inference.

RS3 Sequence needs true context and matching tracr features; it is not Sequence+Target. Training-union exact-spacer exclusions do not imply near-match exclusions or a different publication's internal protocol. Reproduce source duplicate-key row weighting only as an explicitly labeled source replay; retain deduplicated sensitivity separately.

BE-Hive editor/cell/endpoint identity matters. A weak external any-edit efficiency result must not be hidden or renamed as intended genotype precision. PRIDICT2 grouped OOF must use only the correct held-out fold, not all-fold training-exposed ensembles. DeepPrime requires its original sequence/numerical inputs, system/scaffold and source ensemble. Complete pretraining disjointness must not be assumed from fine-tuning group separation.

RFcombined's paper/final-model and comparative-source parameter variants differ. A finished source-method reimplementation must disclose which version ran. Train-only scaling, original split seeds, labels and precomputed/global feature-selection limitations remain material. Split/refit percentiles are not independent-target confidence intervals.

Specificity benchmarks need experimentally assayed positives AND negatives, matched nuclease/guide/cell/assay, and declared detection thresholds. Unassayed nominations are not negative labels. Panel-exhaustion recall at K is not genome-wide recall. Population haplotypes, bulges and structural variants remain untested unless directly evaluated.

Keep same-row label cohorts for paired comparisons; unequal score-column coverage invalidates a direct comparison. Treat declared missing predictions as missing, never zeros. Quote exact metric/unit/n and resampling assumptions; raw sequence identity and phenotype independence are different leakage questions.

Only finished, independently checked native-model/endpoint evaluations belong in a completed-only benchmark publication tree. Source-score replays, heuristic components and incomplete tasks belong in history outside benchmark/. Keep scientific caveats and weak measurements with completed results; do not remove caveats to satisfy the folder policy. No native result licenses therapeutic or biological-safety claims.

## Harness interpretation

Apply references/harness-integration.md and the reproducible-scientific-harness skill. Completed native endpoint evidence and incomplete application status are separate. A fresh control replay verifies reproducibility, not an improved model; metadata checks and readable files do not prove native feature authenticity. Learned random placeholders, fabricated context and cached scores labeled as fresh are invalid. Declare active native dropout and subset/order dependence. Do not train replacements when pretrained-only execution was requested.

Retain explicit missingness and threshold conventions. Only matched cohort, endpoint and protocol permit a matched-protocol delta; keep it null otherwise. New configuration trajectories need not be monotonic, and previously examined labels do not become independent holdouts. Preserve prior manifests and weak results. Keep partial/cached-only/software-only attempts in history rather than relaxing this package's completed-only benchmark publication policy.
