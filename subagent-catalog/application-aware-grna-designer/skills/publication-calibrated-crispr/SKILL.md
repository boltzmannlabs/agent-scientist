# Publication-calibrated model and comparison policy

Use references/model-policy.json for the narrow evaluated conditions and references/benchmark-evidence.json for historical measured summaries. The package carries policies, not pretrained models or underlying datasets. Historical execution does not validate a recipient backend or this specialist's live behavior.

1. Review actual biological context and parent permissions before model selection. Pathogen-associated operational design/optimization is review-only. A flag, file or fixture is never permission or safety clearance.
2. Run scripts/policy.py on request metadata only. The helper reads its own policy, not models, targets or datasets. Success always requires native contract and parent authorization checks; it never authorizes inference.
3. Retain native PRIDICT2 and DeepPrime ensembles. Do not infer PE-system compatibility from a cell match alone. Preserve matched folds, editors, scaffold and measured endpoint.
4. Keep RS3_refit_reference opt-in research-only. Increased training coverage confounds its small improvement; no automatic default promotion. Keep native BEHive and RFcombined pending stronger matched transfer evidence.
5. Treat CRISPRon-CBE as a separate research endpoint. Distinguish generic CLI mixture, source-matched paper recommendation, one-dimensional efficiency and joint rho2. Do not compare its author-label score to the older BEHive external-panel score as an upgrade. Exact V0pretraining membership remains unresolved.
6. Freeze candidates, group splits, labels, endpoint definitions and resampling before scoring. Select using validation only. Do not promote a maximum-test winner or claim a public-test development split is blinded validation.
7. Validate native features and genuine sequence context; preserve input identities across23nt/30nt views. If using atomic native stages, first check a label-independent subset against the unchanged author pipeline.
8. Capture commands, unique logs, source/model/config hashes, environment versions, source exclusions and actual predictions. No feature/label imputation, guessed flanks, synthetic scientific truth, heuristic replacement scores or clinical guarantees.
9. Separate metadata checks, native fixtures, genuine inference, metric replay and experimental validation. A policy or dependency checker PASS never establishes performance. Keep blocked and partial attempts outside completed-only benchmark registries.

This skill is complete as a portable metadata policy module: scripts/policy.py and both supporting JSON files are local to this folder. Agent tools, approval, real reference data, scientific runtime and weights are external prerequisites.
