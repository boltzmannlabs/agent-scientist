# Governed application-aware guide RNA workflow

Apply the leaf's instructions and parent policy; never expand permissions. This is a procedural skill, not a scientific model or install bootstrap.

1. Confirm mode, application, system, target, reference versions, input provenance and approved output root. Return missing scientific/authorization inputs to the parent.
2. Separate routing from readiness: metadata completeness is not a runnable backend. Check safety/provider prerequisites before local setup or uploading anything.
3. Read the original scientific task contract. Check each native tool, exact features and original weights in the selected isolated environment. No heuristic substitutes or synthetic biological results.
4. Freeze input/reference/model identities and create a fresh run. Verify genome/transcript/variant orientation and PAM/coordinate conventions. Keep source files unchanged.
5. Execute only scientifically defined, authorized stages. Save actual commands/exits, raw outputs, endpoint-specific values and NOT_RUN reasons. Do not convert a partial application into a complete benchmark.
6. Rank only under an applicable versioned contract with genuinely executed required endpoints. Do not add new scores, inferred probabilities, fallback composites or unstated gates.
7. Benchmark only against matching measured labels with declared exclusion/split/resampling. Preserve native model identity and endpoint, source-style replay vs sensitivity analysis, and assay-specific detection limits.
8. Publish only completed verified native model/endpoint benchmarks in benchmark/. Incomplete attempts and source-score-only reviews belong in execution history. Keep material limitations and weak results with accepted evaluations.
9. Verify output shapes/joins/identifiers/artifact hashes and all asserted totals. Return real paths and an honest execution class. Keep best_design=null absent independent evidence; no experimental or clinical validation claim.

Local native backend setup and scientific execution are separate from installation of this specialist package. No backend is bundled here.

Load the companion reproducible-scientific-harness skill and the leaf package's harness integration reference for the enforced evidence contract. Preserve CRISPR versus siRNA modality boundaries; an RNAi request is not a Cas13 request. Use the package's request-result JSON Schema for request preflight/rejection output and schema_version=2 in its scientific run-record schema. Run the package's harness audit CLI only as an offline consistency check, with explicit artifact-root approval before file hashing. Those references and scripts are parent-supplied package resources, not bundled dependencies of this procedural skill. A passing metadata, schema or artifact check never grants source access, certifies model readiness or proves biological efficacy.
