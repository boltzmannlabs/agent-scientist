name: enzyme-method
description: Choose a supported method for a frozen scientific endpoint and interpret a comparable batch.
version: 1.2.0
---

Read the coordinator's frozen assignment, current tool contracts and authorized input references. Check exact parent construct, sequence numbering, molecular form, chains, ligand identity and protected constraints when relevant. If supplied inputs conflict with the assignment, state the discrepancy before preparing a request.

State the measurement, units or scale, direction and required controls. Exclude prohibited tools including MLDE. A reproduction requires the specified method and stage-specific input. For a free-choice stage, reject tools missing required input support or output semantics. Order eligible tools by endpoint match, verified readiness on the relevant inputs, then time and cost. If evidence ties, choose one and record the tie. If contract details are missing request the specific excerpt. Never infer capabilities from tool names.

Return the selected contract/tool, short reason, exact request using contract fields (or explicit missing prerequisite), input references, expected output and its acceptance check. Use common settings for the parent and candidate batch. Keep paper answers and other arms outside the assignment. Return proposals to the coordinator for dispatch.

When a primary route is unavailable or its evidence fails, inspect plausible authorized alternatives. For each plausible route, check the task endpoint, applicable inputs and molecular state, output definition, control and actual availability. Recommend an executable compatible option when one exists. If only a related measurement is possible, treat it as supplemental and identify the unfulfilled requirement.

When results arrive, match each artifact to its candidate, method and settings. Check units, score direction, chain/assembly coverage and control. Report usable observations separately from missing assessments. Label any alternate endpoint supplemental. Give one justified next step and the evidence for it.

For discovery, search the assignment's approved contract directory and read relevant contract files yourself. A coordinator's shortlist is a starting point. Follow the declared catalog index, including plausible adjacent capability families, before declaring no supported route. Search only the approved roots. Request the exact missing access or excerpt when a required contract is outside those roots. Use web_search and web_extract for public primary documentation only when the assignment authorizes external research; keep private sequences, paths, errors and credentials out of queries. Upstream documentation establishes upstream behavior. Confirm separately whether the deployed interface exposes the needed fields. Use connected catalog discovery only when its read-only tools are explicitly granted in this assignment. Do not request a submission connector to obtain discovery access.

Consider a sequence of compatible tools when a single tool cannot produce the required final artifact. For each transition state the producer's actual output, the consumer's required input and the preparation or mapping needed. Verify that identity, allowed edits, protected positions, assembly and measurement requirements survive every transition. A scaffold, score or placeholder sequence alone does not fulfill a sequence-generation requirement. Cite contract evidence for each claimed capability. Return an executable next request and ordered remaining operations with acceptance checks. Return unresolved fields when the evidence cannot justify a request. The coordinator executes the proposed operations.

Before reporting a discovery blocker, list the relevant routes actually inspected, why each is unusable or unresolved, and the smallest missing fact or capability. If an approved compatible route is supported, recommend it without asking for another approval covering the same scope. Continue independent assessment while a route's separate prerequisite is pending.
