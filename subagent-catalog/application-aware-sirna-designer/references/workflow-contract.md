# Run and evidence contract

Inputs are immutable; select a fresh run ID automatically unless the user supplied one. Freeze task/config/target reference/model/checkpoint/native-mode/label-rule/split/metrics and record SHA-256 of actual approved files before scoring. Missing hashes stay blockers; do not invent zeros. Run records use version 2; preflight output is a separate schema, never padded with fake native provenance. Preserve prior v1 records rather than normalizing source tokens.

DESIGN generates then evaluates; EVALUATE does only requested properties; BENCHMARK joins unchanged labels after prediction; EXPLORATORY proposes briefs and bounded strategies, never hidden gate relaxation. SETUP is software/asset preparation only, AUDIT is a capability/evidence review. Eleven task frames share underlying engines and may reuse identical scientific rows; record unique cohorts and configurations separately from directory/bundle counts.

Native score units and endpoint semantics remain separate. Clinical anchors, chemical modifications, reporter selectivity, expression context, immune motifs and seed viability are not substitutes for measured on-target efficacy. Keep censored values and small/degenerate cohorts explicit; unknown training overlap is unknown, not a clean independent cohort. Report both strict and inclusive cutoffs when the source ambiguity matters. Numeric matched-protocol deltas require genuinely matched cohort, endpoint and protocol; otherwise null. No reliable transferable improvement or matched published-protocol superiority was demonstrated in retained Runs 4-6.

The generic auditor validates record consistency only. It never runs listed commands, proves file claims are genuine native inference, certifies a license, authorizes a source read or validates biology. Optional root-confined file hashing/row checks and raster decode/nonconstant checks are integrity checks, not visual or scientific validation. A synthetic fixture can test rejection logic but cannot become a measured benchmark by flipping flags. A completed native endpoint can be published with narrow scope while the full application stays partial. Metadata/software/author-score-only attempts stay in history. best_design=null and experimental_validation=false.
