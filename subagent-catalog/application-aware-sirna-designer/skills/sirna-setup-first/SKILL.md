# Setup-first procedure

1. Triage scope and endpoint; decide provider before provisioning heavy dependencies.
2. Read the complete parent-supplied dependency catalog and local SCI contract; do not infer model readiness from installed instructions.
3. Produce a plan for only required profiles. Collect missing executable, wheel/index, source/egress, storage/resource, license and fresh-prefix approvals through the parent.
4. Execute the approved plan once with the packaged setup CLI; keep the actual receipt/failures. Never mutate SCI, another profile or an existing environment.
5. Verify software metadata, actual assets and a real native fixture independently before target scoring. A package audit or hash does not establish native applicability.
6. Block unavailable licensed assets, invalid/random feature construction and unsupported models. Do not install everything, retrain or silently switch provider.

Read [setup acceptance](references/setup-acceptance.md). Package-level scripts and catalogs are supplied by the parent leaf, not installed by loading this skill.
