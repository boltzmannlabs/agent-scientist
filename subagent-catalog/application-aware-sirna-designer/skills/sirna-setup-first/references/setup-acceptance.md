# Setup acceptance

States are PLAN_ONLY, SOFTWARE_SETUP_VERIFIED_ONLY, ASSET_INTEGRITY_ONLY and reviewed native-fixture readiness. None implies the next state. Standalone Python versions must be provisioned separately. Observe the actual process exits and sources, preserve failed environments and keep credentials out of receipts. A true independent model inference fixture must check exact features, checkpoint identity, cardinality, mapping and native mode. License and source approvals are out-of-band parent decisions; booleans in a fixture are not consent.
